# Past Snap

A Google-Maps-style public photo map.

## Features
- Drag and zoom the map like a normal map
- My Location button
- Tap any location to select it
- Take/select a photo
- Upload photo to Supabase Storage
- Save latitude/longitude in Supabase
- Everyone can see uploaded photo pins

## Supabase setup

1. Create a Supabase project.
2. In Storage, create a bucket named:
   past-snaps
3. Make the bucket public.
4. In SQL Editor, run:

create table public.snaps (
  id bigint generated by default as identity primary key,
  latitude double precision not null,
  longitude double precision not null,
  image_url text not null,
  created_at timestamptz default now()
);

alter table public.snaps enable row level security;

create policy "Anyone can view snaps"
on public.snaps
for select
to anon
using (true);

create policy "Anyone can post snaps"
on public.snaps
for insert
to anon
with check (true);

5. In Supabase Project Settings -> API, copy:
   - Project URL
   - anon/public key

6. Open public/index.html and replace:
   PASTE_YOUR_SUPABASE_PROJECT_URL
   PASTE_YOUR_SUPABASE_ANON_KEY

Never put a service_role/secret key in index.html.

## Render

Build command: npm install
Start command: npm start
Environment variables are not required for this version because the public Supabase URL + anon key are used in the browser.
